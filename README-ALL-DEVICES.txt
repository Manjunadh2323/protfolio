PORTFOLIO — ALL DEVICES VERSION

This folder is prepared for desktop, Android, iPhone/iOS, iPad/tablet and small screens.

Changes include:
- iOS/Safari viewport handling
- safer mobile/touch behavior
- responsive layout hardening
- iPhone/iPad tap and input handling
- orientation/visual-viewport refresh handling
- relative HTML section loading
- Vite build/preview scripts

Run:
1. npm install
2. npm run dev

Production check:
npm run build
npm run preview

Do not commit node_modules. It will be recreated by npm install.
