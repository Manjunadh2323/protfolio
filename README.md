# 💼 Personal Portfolio Website

A modern, responsive personal portfolio built with Django to showcase my projects, technical skills, internship experience, and resume.

## 🚀 Features

- Responsive modern UI
- About Me section
- Skills & Technologies
- Featured Projects
- Internship Experience
- Resume View & Download
- Contact Section
- Smooth scrolling and animations

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- Git & GitHub
